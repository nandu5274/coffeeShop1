# Serverless Email API (Node.js + Vercel + Brevo)

## Steps to use

1. Create a Brevo account and get API key
2. Deploy this project to Vercel
3. Add environment variable:
   BREVO_API_KEY=your_api_key
4. Call API from Angular:
   POST /api/send-mail

## Free limit
- 300 emails/day (Brevo free tier)
